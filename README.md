# Fitnes — информационная система фитнес-клуба

## 📌 О проекте

**Fitnes** — настольное приложение для управления информацией фитнес-клуба. Программа разработана на языке C# с использованием Windows Forms в среде Microsoft Visual Studio. Для хранения данных используется база данных Microsoft Access.

Приложение предназначено для работы с данными фитнес-клуба через графический интерфейс и позволяет просматривать записи, выполнять поиск, а также добавлять, изменять и удалять данные в зависимости от возможностей соответствующих форм.

## 🎯 Цель проекта

Создать удобную информационную систему, которая упрощает работу с данными фитнес-клуба и позволяет управлять информацией через единый интерфейс.

## ⚙️ Используемые технологии

- **C#** — язык программирования.
- **.NET Windows Forms** — создание графического интерфейса.
- **Microsoft Visual Studio** — среда разработки.
- **Microsoft Access** — хранение данных.
- **ADO.NET / OleDb** — взаимодействие с базой данных Access.
- **Git и GitHub** — контроль версий и хранение исходного кода.

## ✨ Возможности приложения

В зависимости от реализованных экранов программа поддерживает следующие операции:

- Просмотр данных в табличном виде.
- Поиск записей по введённому значению.
- Добавление новых записей через отдельные формы.
- Изменение и сохранение данных.
- Удаление записей с подтверждением действия.
- Работа с информацией, хранящейся в базе данных фитнес-клуба.

### Абонементы

В проекте предусмотрена работа с информацией об абонементах, включая следующие поля:

- Код абонемента.
- Название.
- Стоимость.
- Срок действия.

## 🗂️ Структура проекта

Основные элементы проекта:

- `Fitnes.sln` — файл решения Visual Studio.
- `Fitnes.csproj` — файл проекта C#.
- `Form*.cs` — файлы форм приложения.
- `Form*.Designer.cs` — автоматически создаваемый код интерфейса форм.
- `SearchForm*.cs` — формы поиска.
- `AddForm*.cs` — формы добавления записей.
- `*.resx` — ресурсы Windows Forms.
- `*.xsd` — определения типизированных наборов данных, если используются в проекте.
- Файл базы данных `*.accdb` — база Microsoft Access, если она включена в репозиторий.

Фактический состав файлов зависит от текущей версии проекта.

## 💾 Требования для запуска

Для работы с исходным кодом необходимы:

1. Компьютер под управлением Windows.
2. Microsoft Visual Studio с поддержкой разработки приложений Windows Forms на C#.
3. Подходящая версия .NET, соответствующая настройкам проекта.
4. Microsoft Access Database Engine соответствующей разрядности, если он необходим для подключения к базе данных.
5. Файл базы данных Access и корректная строка подключения.

## 🚀 Установка и запуск

1. Склонируйте репозиторий или скачайте исходный код.
2. Откройте файл `Fitnes.sln` в Microsoft Visual Studio.
3. Убедитесь, что файл базы данных Access находится по пути, указанному в строке подключения проекта.
4. При необходимости настройте строку подключения к базе данных.
5. Восстановите необходимые зависимости, если Visual Studio предложит это сделать.
6. Выполните команду **Build → Build Solution**.
7. Запустите приложение с помощью клавиши `F5` или кнопки запуска в Visual Studio.

Если при подключении к Access возникает ошибка, проверьте путь к базе данных, имена таблиц и полей, а также наличие необходимого драйвера.

## 🗄️ База данных

Для хранения информации используется Microsoft Access.

При переносе проекта на другой компьютер необходимо убедиться, что база данных доступна приложению и строка подключения настроена правильно.

Если база данных не включена в репозиторий, её потребуется добавить отдельно или настроить подключение к существующему файлу.

## 🔎 Поиск данных

Для поиска предусмотрены отдельные формы. Пользователь вводит искомое значение, после чего приложение выполняет поиск по данным отображаемой таблицы и выделяет найденные строки.
